APP DE SAÚDE — PROTÓTIPO FRONT-END

Como abrir:
1. Extraia o arquivo ZIP.
2. Abra index.html em um navegador.
3. Navegue pelos links do cabeçalho para acessar as outras páginas.

Arquivos:
- index.html: página inicial
- profissionais.html: busca por especialidade/convênio e opções de horário
- consultas.html: próximas consultas e ações ilustrativas de cancelar/remarcar
- agenda.html: visão de agenda para recepção/profissional, status, disponibilidade e auditoria ilustrativa
- css/style.css: folha de estilos externa compartilhada

Escopo:
Protótipo estático acadêmico, com dados fictícios. Não possui back-end, autenticação, persistência, integração com agenda, notificações reais nem transações de agendamento. Botões de ações não implementadas exibem avisos demonstrativos. A busca GET atualiza a URL, mas os filtros não consultam dados reais.
